# Community

OpenCub is open-source software. Whether you're interested in contributing code, documentation, or just using the project, there are several ways to get involved.

## Contributing Code

Read the [CONTRIBUTING.md](https://github.com/tylerthomas/opencub/blob/main/CONTRIBUTING.md) guide for information on development setup, coding standards, and how to submit your changes.

## Get Involved

- **GitHub Issues**: Open issues for bugs or feature requests, or join existing discussions.
- **Pull Requests**: Contributions are welcome — see the contributing guide above.

## What Does OpenCub Need Help With?

OpenCub could benefit from help across the board:

- Adding support for new AI providers
- Improving tool functionality
- Enhancing the user experience
- Writing documentation
- Reporting bugs or suggesting features
- Design and software craft

All contributions are welcome.
